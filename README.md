# タドリー — 自撮りから他撮り風プロフィール写真へ

マッチングアプリ向けに、自撮り写真を「他の人に撮ってもらったような」自然なプロフィール写真へ変換するWebサービスです。企画・設計・実装・運用まで一人で行っています。

🔗 **サービス**: https://tadory.jp

> このリポジトリはポートフォリオ用の紹介ページです。ソースコードは非公開のため含まれていません。

## 何ができるか

1. **無料お試し**: ログイン不要で1枚生成し、透かし入りのプレビューを返します。
2. **購入**: Stripe Checkoutで決済し、服装などを選びます。
3. **生成・納品**: 複数枚を生成し、ZIPとダウンロードページで納品します。
4. **返金・再生成**: 満足できなかった場合の返金申請と再生成に対応しています。
5. **自動削除**: アップロード写真と生成画像は、期限後に自動で削除します。

## 技術構成

| 用途 | 技術 |
|---|---|
| フロント・API | Next.js 15 (App Router) / React 19 / TypeScript |
| ホスティング・Cron | Vercel |
| DB | Neon Postgres |
| 決済 | Stripe Checkout / Webhook |
| 画像生成 | OpenAI 画像生成API |
| 画像処理 | sharp / heic-convert |
| ストレージ | Vercel Blob（非公開） |
| メール | Resend |
| 濫用対策 | Cloudflare Turnstile / Upstash Redis |
| テスト・CI | Vitest / GitHub Actions |

## 工夫した点

- **決済の整合性**: 支払い状態はStripe Webhookを正として更新します。画面遷移の結果は信用しない設計にしました。
- **画像生成ジョブ**: PostgresをジョブキューにしてWorkerで生成し、滞留したジョブはスイーパーで回収します。
- **個人情報の扱い**: ユーザー写真は非公開ストレージに置き、認証付きAPI経由でのみ配信します。期限後はCronで物理削除します。
- **AI生成コストの濫用対策**: 無料お試しはBot判定と、端末・IPごとの回数制限で守っています。
- **技術選定の記録**: Cloudflare Workers / D1 など他の構成と比較し、採用・不採用の理由をドキュメントに残しています。
- **改善サイクル**: LPの計測、競合調査、プロンプト評価、日次レポートの自動送信など、作って終わりにしない運用を回しています。
